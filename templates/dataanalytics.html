Curriculum
Module Breakdown
1
Excel for Data Analytics
7 Topics
  • Data Cleaning & Formatting Best Practices
  • Advanced Formulas: IF, VLOOKUP, INDEX-MATCH, XLOOKUP
  • PivotTables & PivotCharts
  • Conditional Formatting & Data Validation
  • Power Query: ETL in Excel
  • What-If Analysis & Solver
  • Project: Sales Performance Dashboard in Excel
2
SQL for Data Analysis
8 Topics
  • SELECT, WHERE, ORDER BY, GROUP BY
  • Joins: INNER, LEFT, RIGHT, FULL OUTER
  • Aggregate Functions & HAVING
  • Subqueries & Nested Queries
  • CTEs (Common Table Expressions)
  • Window Functions: RANK, ROW_NUMBER, LAG/LEAD
  • Stored Procedures & Views
  • Project: E-commerce Database Analysis
3
Power BI & Data Visualization
6 Topics
  • Power BI Desktop Interface & Data Import
  • Data Modeling & Relationships
  • DAX Formulas: Calculated Columns & Measures
  • Interactive Visuals: Charts, Maps, KPIs
  • Report Design Principles & Storytelling
  • Project: Business Intelligence Dashboard
4
Python for Analytics & Capstone
6 Topics
  • Pandas: Load, Clean, Transform Data
  • Exploratory Data Analysis (EDA)
  • Matplotlib & Seaborn Visualizations
  • Automating Repetitive Reports with Python
  • Introduction to Statistical Analysis
  • Capstone: End-to-End Analytics Project with Presentation
